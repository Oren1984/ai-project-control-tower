# Static Demo Site — AI Project Control Tower

A portfolio-ready static site explaining the AI Project Control Tower system.

## Contents

```
static-demo/
├── index.html    Main single-page demo site
├── styles.css    Dark theme styles
├── app.js        Smooth scroll + nav + score bar animations
└── README.md     This file
```

## Running Locally

```bash
python -m http.server 8000 -d static-demo
```

Then open: http://localhost:8000

No build tools, no dependencies. Pure HTML, CSS, and JavaScript.

## What the Site Covers

- What AI Project Control Tower is and why it exists
- What it does vs. what it does not do
- The 6-step audit workflow
- All 9 audit quality dimensions
- Architecture component diagram
- Static demo report card (labeled as a static example)
- Example audit scores across dimensions
- All 7 safety boundaries with enforcement method
- Tech stack
- Portfolio narrative and interview talking points

## Notes

- Report cards in the demo are clearly labeled **Static Demo Example** — they are not real audit output
- The site reflects the actual system architecture (Waves 1–6)
