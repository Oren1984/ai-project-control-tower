## Safe-to-Delete Items (Cache and Generated Files)

The following items are safe to delete. They are:
- Listed in `.gitignore`
- Automatically regenerated by Python/pytest on the next run
- Not source code, tests, documentation, migrations, or configuration

```bash
# Delete all __pycache__ directories
find . -type d -name "__pycache__" -not -path "./.git/*" -exec rm -rf {} +

# Delete .pytest_cache
rm -rf .pytest_cache
```

**On Windows (PowerShell):**

```powershell
# Delete all __pycache__ directories
Get-ChildItem -Recurse -Filter "__pycache__" -Directory | Remove-Item -Recurse -Force

# Delete .pytest_cache
Remove-Item -Recurse -Force .pytest_cache -ErrorAction SilentlyContinue
```
